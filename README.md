# لوحة قيادة المدرسة

تطبيق ويب عربي (RTL) لمدير/قائد المدرسة يعمل دون اتصال بعد أول تحميل ويمكن تثبيته (PWA) على الجوال والحاسب.
البيانات تُحفظ في متصفح الجهاز فقط (localStorage) مع تصدير/استيراد نسخة احتياطية JSON مُتحقَّق من سلامتها (SHA-256).

الرابط: https://alotibi21-spec.github.io/school-leader-dashboard/

الخط: Tajawal (SIL OFL 1.1).
